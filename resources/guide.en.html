Sonitrelix user guide

From your first recording to a multitrack mix. For Sonitrelix on Windows.

English · Leer en español

Use Sonitrelix to record, edit and mix audio while preserving your original files. You can switch between English and Spanish in Preferences.

1. Beginner: get started

Extract and start the portable application

  1. Extract the portable ZIP to a writable folder, such as a folder in Documents. Do not run the application from inside the ZIP.
  2. Open the extracted folder and run Sonitrelix.exe. Keep its accompanying files together.
  3. Use Tab and Shift+Tab to move between controls. Use Alt to reach the menu bar and arrow keys to browse menus.

Sonitrelix stores settings, logs and generated audio in a data folder beside the executable. Deleting that folder can delete audio used by your projects.

Read this guide without a mouse

Press F1 in Sonitrelix to open the read-only user guide. Press Tab from the guide text to Open HTML guide, then press Enter to open it in your browser. In the text viewer, choose a section and press Enter; use Ctrl+F to find text, F3 for the next result, and Escape to close.

In the browser, use the contents links or your screen reader’s heading and table shortcuts in browse mode. Ctrl+F finds text. Alt+Tab returns to Sonitrelix.

Understand tracks, clips and focus

Project
The saved arrangement of tracks and references to their audio.
Track
A named sequence of audio clips and silence. Each track has mute, solo, recording-arm, volume and pan settings.
Clip
A region referring to part of a source recording, or an explicit silence region.
Cursor
The position where playback or an edit starts.
Selection
A start and end time defining the audio you want to edit.

The main window has menus, transport controls, a Tracks list, a Clips list, editable time fields and readouts. Use Up/Down in a list to choose a track or clip. Most audio shortcuts work only while Tracks or Clips has focus. In a text field, Ctrl+A/C/X/V edit text instead of audio.

Choose your microphone and headphones

  1. Press Ctrl+, to open Tools > Preferences.
  2. Use Ctrl+Tab to reach Audio devices.
  3. Select the input microphone and output device independently. Use the refresh control after connecting a device.
  4. In Recording / playback, choose recording channels and buffering. Match mono/stereo to an existing track you plan to record into.
  5. Choose Apply to save while keeping Preferences open, or OK to save and close. Cancel discards changes you have not applied.

Use headphones when recording over music. You can hear the backing track during recording. To hear your microphone too, enable Monitor microphone while recording under Recording / playback. Monitoring starts off and does not change the recorded level.

Import and hear an audio file

  1. Press Ctrl+I, choose an audio file in the standard file dialog, and open it.
  2. Wait for import to finish. Compressed audio is converted into a WAV asset in the background.
  3. Focus Tracks or Clips. Press Space to play the audible project mix.
  4. Press Ctrl+Space to pause/resume, or Space to stop. Press F6 to focus the transport readout.

Ctrl+I opens WAV, MP3, FLAC and AAC in M4A using the built-in importers. Escape cancels an active import from the main window.

Extra formats and effects with FFmpeg

The official Windows ZIP includes ffmpeg.exe beside Sonitrelix.exe. If you build Sonitrelix yourself, place a compatible Windows FFmpeg build beside it or on PATH. With FFmpeg available, Ctrl+I also handles Ogg Vorbis, Opus and AIFF. Choosing a supported video file imports its first audio stream.

Make a simple voice recording

  1. Start a new project with Ctrl+N. Save any previous work when asked.
  2. Press Ctrl+Shift+N to add an empty track. Focus Tracks, press F2, type a name, and press Enter to confirm it.
  3. With the track selected, press A to arm it for recording. Press Home to start at zero.
  4. Press R to record. Speak into the selected microphone. F6 reads the transport snapshot.
  5. Press Ctrl+Space to pause or resume. Press Space to finish the recording. R also finishes it when Tracks or Clips has focus.
  6. Return focus to Tracks or Clips and press Space to hear the new take from its start.

Capture creates WAV assets in data/recordings. Keep them even after saving a project. If recording reports an error, inspect and save any completed audio before retrying.

2. Beginner: edit and save audio

Set a cursor or selection precisely

The time format is hours:minutes:seconds.milliseconds. For example, 00:01:15.000 is 1 minute 15 seconds. Select the track, Tab to Position or the selection start/end fields, enter the desired values, then activate Apply times.

To select from 1 minute 15 seconds to 1 minute 28.5 seconds, enter 00:01:15.000 and 00:01:28.500. Press F7 to focus the selection readout. Return focus to Tracks/Clips before using audio-editing shortcuts.

Alternatively, move with Left/Right; hold Shift to extend a selection. Ctrl uses the larger step. Configure the step sizes in Preferences. Enter on a clip selects that entire clip with exact sample boundaries. Escape in Tracks/Clips clears the audio selection.

With Tracks or Clips focused, press [ at the start. Move or let playback reach the end, then press ]. Both marks use the current playhead during playback. Press F7 to read the range, then return focus to Tracks or Clips. Ctrl+E opens Effects for the range, Delete removes it, and Ctrl+Shift+X exports it.

Copy, cut, paste and delete

  1. Select a time range on a track.
  2. Press Ctrl+C to copy or Ctrl+X to cut. Cut closes the gap.
  3. Select the destination track and place its cursor. Press Ctrl+V to paste. Existing later audio shifts to make room.
  4. Press Ctrl+Z to undo, or Ctrl+Y to redo, while outside a text field.

Paste replaces an active selection. Clear the selection with Escape first if you want to insert at the cursor instead. The audio clipboard is internal to Sonitrelix and does not exchange audio with other applications. Copy/paste between nonempty tracks requires compatible channel/rate formats; an empty destination can adopt the copied format.

Ctrl+A selects all audio on the selected track, not all tracks. To cut an entire track’s audio, press Ctrl+A then Ctrl+X. Delete removes selected audio and closes its gap; it does not delete the source file.

Split, trim and insert silence

  • Split at cursor (Ctrl+T) makes a boundary without removing audio.
  • Trim to selection (Ctrl+Shift+T) keeps only the selected interval on that track.
  • Silence selection (Ctrl+L) replaces the selected audio with silence and keeps its duration.
  • Insert silence (Ctrl+Shift+I) adds silence at the cursor, shifting later audio. Its duration is the selection length, or one second when no range is selected.

Repeat a selection and mark important places

Mark both ends with [ and ], then press F3 in the main window. The project mix repeats between those times. Press F3 or Space to stop. Ctrl+Space pauses or resumes. Starting ordinary playback again plays without looping.

With Tracks or Clips focused, press Ctrl+M at the cursor and enter a name such as Chorus. Use F9 to jump to the previous marker or F11 for the next. Sonitrelix announces the name and time. Transport > Manage markers lets you jump to a marker or delete it. Save the project to keep the markers.

Smooth the join between two clips

Focus Clips, select the clip immediately after the join, and press Enter to move to its start. Press Ctrl+Shift+F. Sonitrelix blends the last 20 ms of the first clip with the first 20 ms of the second clip, or uses a shorter overlap for short clips. Later audio on this track moves earlier by the overlap length. Other tracks keep their timing. Ctrl+Z restores the original join.

Open a direct audio link

  1. Choose File > Open audio link or press Ctrl+U. Paste a direct HTTP or HTTPS link to a file such as MP3, WAV or FLAC, and press Enter.
  2. Wait for Linked audio to appear as a new track, then use Space to play. Escape cancels an active download.
  3. For an overdub, add another track with Ctrl+Shift+N, arm it with A, and press R. Use headphones and leave the linked track audible.

The audio is stored in data/imports so the project can reopen offline. Keep that folder with the project. Use a link that downloads the audio file directly. A web page or live stream cannot be imported this way.

Save a project or create an audio file

Ctrl+S saves a .sonitrelix project; Ctrl+Shift+S saves under another name. A project remembers the arrangement and source references. It is not a playable mix file and does not embed its audio.

Ctrl+Shift+E exports the audible mix to an audio file you can share. Save the project too if you want to continue editing. Undo history and the current cursor/selection are not restored when you reopen a project.

3. Intermediate: record vocals over music

Prepare the backing track and vocal track

  1. Import the instrumental with Ctrl+I. Select its track, press F2 and name it Instrumental.
  2. Add an empty track with Ctrl+Shift+N and name it Vocals.
  3. Check input/output devices in Preferences and put on headphones.
  4. Select Vocals and press A to arm it. Check that the instrumental is audible: it must not be muted or excluded by solo.
  5. Move the cursor to the desired start. R records Vocals while the other audible tracks play.
  6. Ctrl+Space pauses/resumes both streams. R or Space stops. The completed vocal region appears in its track.

Recording uses one target track at a time. Its existing audio is excluded from backing playback. New capture replaces the destination interval without shifting later audio; recording at a later position adds silence before it when necessary.

Record audio from speakers or headphones

In Tools > Preferences > Audio devices, choose Loopback followed by the name of your speakers or headset under Recording input. The Windows default loopback entry follows the default playback device whenever a recording starts. Apply the choice. For stereo capture, choose Stereo in Recording / playback.

Arm a track with A and press R. Play sound on the selected output. F8 reports the system audio peak, Ctrl+Space pauses or resumes, and R or Space stops and adds the take. Everything routed to that output can be captured, including screen-reader speech and notifications. Sonitrelix leaves project playback and monitoring off during loopback. To record over project backing again, select a microphone.

Redo a phrase with punch-in recording

Select and arm the track with the existing take, then mark the phrase with [ and ]. Use headphones and press Ctrl+Shift+R from Tracks or Clips. Playback starts up to three seconds early. The armed track can play during the lead-in, and other audible tracks continue during the recording. The microphone take replaces only the marked audio and stops automatically at the end. Press Ctrl+Z to restore the original take. If you stop after capture starts, the completed portion is kept.

Balance and organize tracks

With Tracks/Clips focused, M toggles mute; S toggles solo; A toggles recording arm. Solo is stored per track. If one or more tracks with audio are soloed and unmuted, the mix plays those tracks together. A muted or empty soloed track does not silence the other tracks.

Mute and solo take effect during playback. The playhead keeps moving even when all tracks are silent. A, S and M keep focus on your track. Solo feedback can also tell you when the track is muted or empty, or when several tracks are soloed.

Ctrl+G opens Volume and pan for the entire track. The Alt+Arrow shortcuts also affect the entire track. To change the volume of a time range, select it and use Effects > Amplify. Adjust the sliders with the arrow keys. Volume ranges from −60 to +24 dB. Pan ranges from −100 on the left through 0 at center to +100 on the right. The individual Reset buttons return volume to 0 dB or pan to center. Choose OK to commit.

With Tracks focused, press Alt+Up or Alt+Down to change the selected track’s volume by 1 dB. Alt+Left or Alt+Right moves its pan by five percentage points. Playback continues while you adjust. Sonitrelix announces the new value. Ctrl+Z undoes the change.

Ctrl+Shift+D duplicates a track. Alt+Shift+Up/Down reorders it. Ctrl+Shift+Delete deletes the selected track from the project. Undo restores a removed track; source assets remain on disk.

4. Intermediate: apply effects and export

Preview and apply an effect

  1. Select the track. To process part of it, focus Tracks, move to the start, press [, move to the end and press ].
  2. Press Ctrl+E to open Effects. The dialog title gives the selected times or says Entire track. If you have only marked the start, mark the end first. Choose an effect and adjust its settings.
  3. Use Preview for a short audition, and Stop preview before making another comparison.
  4. Choose Apply to process in the background. Cancel closes without applying a new edit.
  5. Listen to the result. Ctrl+Z restores the earlier audio if needed.

Effects create new audio assets rather than rewriting originals. They are undoable rendered edits, not a live plug-in chain. A preview is only a short excerpt; listen to the full result before exporting.

Amplify and Normalize
Change level. Start with small gain changes; normalization sets a peak target, not perceived loudness.
Fade In and Fade Out
Increase or reduce level across the chosen region. Useful for entrances and endings.
Reverse and Silence
Reverse sample order, or replace the region with silence.
Basic EQ
Adjust low, middle and high frequency balance.
Compressor
Reduce peaks above a threshold. Compare the result at a similar listening level.
Noise Gate
Reduce quiet passages below a threshold. An aggressive setting can remove quiet words.
Reverb
Add a reverberant sound. Preview a small amount first so words remain clear.

In Effects and Volume and pan, use Tab to move from each slider to its Reset button. Use the arrow keys for small changes or Page Up and Page Down for larger ones. Home and End jump to the limits.

Activate Reset with Space to restore that setting’s default. Choose Apply in Effects or OK in Volume and pan to commit your changes.

Clean up vocals and adjust tempo with FFmpeg

Ctrl+E offers Noise Reduction for steady noise, De-esser for sharp S sounds, De-hum for a 50 or 60 Hz buzz, and Change Tempo for speed changes that preserve pitch. Changing tempo shifts later audio on the edited track. Preview, Apply and Ctrl+Z work as with the built-in effects.

For Automatic Ducking, select the backing track and choose the controlling voice inside Effects. The voice lowers the backing at matching times. Preview plays the processed backing alone. Apply makes an undoable edit to the backing. Play the project to hear both tracks together.

Noise Reduction estimates the background from quieter parts of your selection. Include a brief pause with the steady noise you want to reduce.

Use FastPlugs effects

Download the Windows x64 ZIP from the FastPlugs release. Extract FastPlugs.clap into the Sonitrelix data/plugins folder, install it in the Windows CLAP folder, or select the extracted file when prompted by Effects > FastPlugs.

Mark a range on the track and open Effects > FastPlugs. Choose an effect and use Parameters to read and change its controls. Choose Preview to listen or Apply to process the range. Ctrl+Z restores the previous audio. The edit keeps its length. For reverb or echo decay, include silence at the end of the range.

Export the mix or a selected range

  1. Press Ctrl+Shift+E for the audible mix, or Ctrl+Shift+X for the marked range on the selected track.
  2. In Export Options, choose the format, sample rate, and mono or stereo. MP3 shows a bitrate field. WAV and FLAC use 16-bit lossless audio. With FFmpeg installed, M4A uses AAC at 192 kbps, and Opus uses 128 kbps at 48 kHz.
  3. Choose Metadata if you want to add tags. The fields are title, artist, album, track number, year, genre, and comment. Leave any field blank to omit the tag. FFmpeg writes the tags. Players vary in how they display WAV tags.
  4. To reuse the quality choices, check Use these settings as defaults. Continue opens the Windows Save dialog for a filename and folder. The extension follows the format you chose.

Press Enter to continue with the displayed defaults. The title tag is separate from the filename. Full-mix exports retain the tags in the project; press Ctrl+S to save them. You can give an excerpt its own tags without changing the project's tags.

Escape cancels an active export and preserves any existing destination. Choose WAV or FLAC when you need exact duration because compressed formats can add encoder padding.

5. Set up your preferences

Open Tools > Preferences with Ctrl+,. Use Ctrl+Tab or Ctrl+Shift+Tab to change category. Tab visits controls. F1 or Ctrl+H opens category help while Preferences is active.

  • General: language, new-project sample rate and automatic update checks. Language defaults to Automatic. It uses Spanish when the Windows display language is Spanish and English otherwise. You can choose English or Español explicitly.
  • Audio devices: independent input/output endpoints and refresh.
  • Recording / playback: recording channels, buffering, manual alignment offset and optional headphone monitoring.
  • Editing / keyboard: cursor step sizes and Keyboard shortcuts.
  • Accessibility: detailed time reading and available focus/status options.
  • Export: output rate, channels and MP3 bitrate.

Preferences survive restarting the same portable copy. If you extract a different copy, it has its own data/preferences.json. Use Apply or OK to save changes.

Customize editing shortcuts

In Editing / keyboard, open Keyboard shortcuts, choose an action and enter a chord. The available actions cover editing, tracks, effects and transport. Apply Preferences to save. Conflicting or reserved combinations are rejected. Global project/help keys remain fixed.

The tables below show defaults. After customization, use the chords shown in your settings. Plain letter keys are intended for Tracks/Clips, not text entry. Language changes labels, not the physical default combinations.

6. Advanced: precise timing and project safety

Check microphone and playback levels

Choose Transport > Test recording input before recording. Speak into the selected microphone or play sound on the selected loopback output, then press F8 for its peak. The test stops after 30 seconds, or press Escape to end it. The test does not save audio or send the microphone to the speakers.

During playback or recording, F8 reports the peak in dBFS since your last check, or since the stream started for the first check. During an overdub, it reads the microphone and backing output separately. Clipping stays flagged until a new stream or test starts. During a recording you also get one warning the first time the microphone clips. Lower the input gain at the microphone or in Windows.

Measure the recording offset

Choose the input and output you want to measure in Preferences. Choose Tools > Calibrate recording offset and follow the prompt. The microphone must hear the speakers, or the selected input must receive the test signal through a wired loopback. Three short sounds play. If the measurement is consistent, confirm to save it to Recording / playback. If you change the devices or buffer size, measure again or adjust the manual offset. Escape cancels the test.

Compensate for recording delay

If recorded vocals land late, test a negative Recording alignment offset in milliseconds under Recording / playback. Positive values place capture later; negative values place it earlier, clamped at the project start. The permitted range is −2000 to +2000 milliseconds.

  1. Record a brief clap or click while listening to a known backing cue through headphones.
  2. Compare its timing with the cue. Adjust the offset and make a new test take.
  3. Repeat after changing devices or buffering. Also test pause/resume and a long take.

The offset affects new recordings, not existing clips. Sonitrelix coordinates stream starts. Optional calibration measures delay using a test signal. Long takes can still drift. The project’s rate and each track’s rate can differ; playback/export resamples in the background. Copy/paste compatibility rules are separate.

Keep projects and media together

Back up the .sonitrelix file, all referenced originals and generated data audio folders. Save As changes the project filename, not the location of its assets. Renaming/moving a referenced source can prevent playback. There is no automatic media relinking or self-contained project bundle.

Clips are consecutive regions with silence gaps. Split and ripple edits are supported; freely dragging/moving overlapping clips is not. Plan edits on a duplicate track when trying a different arrangement.

Recover unsaved project changes

While a project has unsaved changes, Sonitrelix makes a metadata checkpoint about every 30 seconds. After an abnormal exit, startup may offer recovery from an exited instance. Recover, inspect the result and save a named project. If Sonitrelix stopped during a take, reopen the original recording from data/recordings with Ctrl+I. For an interrupted Sonitrelix PCM16 recording with a readable header, import can copy whole audio frames left after the last header checkpoint. Inspect the recovered track and align it if needed. This cannot restore unwritten audio.

File > Recent Projects keeps up to ten paths. A missing recent file produces an error; it does not restore its media.

Check and install updates

Portable copies check for updates when they open and every 24 hours while running. You can turn off automatic checks in Preferences > General. Help > Check for updates checks stable GitHub releases on demand. A portable build can install a newer release only when its signed manifest and executable pass verification. Save work and stop recording first. Install update shows download progress in this window. Use Cancel transfer to stop it. Skip this version confirms when the preference is saved and suppresses automatic offers for that version. A manual check can offer it again.

Installation preserves data and keeps an executable backup. Failed startup triggers rollback. Builds without the portable marker offer manual downloads.

8. Troubleshooting and current limits

No playback or microphone signal

Check Windows volume, microphone privacy permissions and your selected input/output. Refresh devices after reconnecting USB hardware. For playback, check mute/solo; for recording, select and arm a target track and verify channels. If your selected microphone disconnects, reconnect it or choose another input in Preferences before trying again.

A shortcut types text or does nothing

Return focus to Tracks or Clips using Tab. Check customized bindings. In a browser, Alt+Tab back to Sonitrelix first. In text fields, ordinary typing and text clipboard shortcuts intentionally retain their Windows behavior.

A project cannot find its audio

Restore the source at its saved path from your backup. Save As does not collect media. Do not delete data/recordings or data/imports just because the project file has been saved.

Import or export fails

Try a supported WAV file and a writable destination first. Check free disk space and Windows media components. For MP3, choose a supported sample rate/bitrate/channel combination. Preserve the original files and avoid retrying by overwriting them.

Report a problem

Include the version from Help > About, Windows version, screen reader/version, selected devices, the exact keys used and the error text. Errors are in data/error.log next to the portable executable, under its data folder. The session event log is data/session.jsonl. Review logs before sharing; they may include local paths. Do not share private recordings or update-signing keys.

For recent changes or version information, open Changelog or About from Help.
